C++11/14 Bootstrap

Gašper Ažman
Workshop leader

Workshop detail

C++11/14 is not just a minor upgrade, it has been described by many as a new language!... This one-day bootstrap course will get you up-to-speed with the language changes you are most likely to employ in your daily work. We will explore the new features with clarifying examples while discussing practical uses and gotchas.
