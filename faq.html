FAQ

How are workshop presenters selected?

All our workshop speakers are of the highest quality and reputation. Many are from code camp directly and the ones that are not likely have spoken at other similar events and could have spoken at code camp

How many days is Code Stars Summit?

Typically, Code Stars Summit events are between 1 and 4 days. You do not need to attend all the days, just the days you have workshops scheduled.

Are meals and snacks served at Code Stars Summit?

We will be providing lunches and snacks during the day. More details will be provided later.

Where is Code Stars Summit Being Held?

Code Stars Summit is held at different locations. Check the the home page for more details.

What Are the Hours For Code Stars Workshops?

Code Stars Workshops typically start at 9AM and end at 4PM. They are always full day workshops.

Thank you to everyone who taught and attended.

Code Stars Summit was part of Silicon Valley Code Camp. There are no future events planned.
